# megability website

A clinic website design template by **Megability** — the "Bright Horizons" pediatric-care layout, offered as a ready-to-use template for clinics.

The Sunny chatbot widget has been removed; clients get Sunny wired to their own Voiceflow project during setup.

## Run locally

**Prerequisites:** Node.js

```bash
npm install
npm run dev
```

## Deploy

Static Vite build (see `vercel.json`). Auto-deploys on push when the repo is connected to Vercel.
